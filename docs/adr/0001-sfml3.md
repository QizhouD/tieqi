# 0001 迁移到 SFML 3.1

- 状态：已采纳
- 日期：2026-10-27

## 背景

本项目从 2D-action-game 框架起步，框架基于 SFML 2.6。SFML 3 于 2024 年底发布，接口与 2.6 不兼容。现在玩法代码还没开始写，迁移成本最低。

## 决定

- 使用 C++20 与 SFML 3.1.0。所有依赖用 CMake FetchContent 从源码构建并锁定版本，默认静态链接，关闭网络模块。
- 调试界面用 Dear ImGui v1.91.9b 与 imgui-sfml 3 系列（master 分支上锁定到具体提交），只在开发版编译。
- 从框架复制的主循环、窗口、资源、音频、粒子、存档代码，按 DEVELOPMENT.md 的迁移表改到 SFML 3。

## 影响

- 事件改为 `std::optional<sf::Event>`；`sf::Text`、`sf::Sprite`、`sf::Sound` 没有默认构造；`Quads` 图元被删除。完整迁移要点见 DEVELOPMENT.md"从 2D-action-game 迁移到 SFML 3"。
- 音频后端是 miniaudio，不再附带 `openal32.dll`。
- 3.1 的文字排版用 HarfBuzz 塑形，中韩文字渲染更稳。
