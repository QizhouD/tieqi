# 0001 Move to SFML 3.1

- Status: accepted
- Date: 2026-10-27

## Context

This project starts from the 2D-action-game framework, which is based on SFML 2.6. SFML 3 was released at the end of 2024 and its interface is incompatible with 2.6. No gameplay code has been written yet, so migrating now costs the least.

## Decision

- Use C++20 and SFML 3.1.0. All dependencies are built from source with CMake FetchContent and pinned, linked statically by default, with the network module off.
- The debug UI uses Dear ImGui v1.91.9b and the imgui-sfml 3 series (pinned to a specific commit on the master branch), compiled only in dev builds.
- The main loop, window, resource, audio, particle, and save code copied from the framework is updated to SFML 3 according to the migration table in DEVELOPMENT.md.

## Consequences

- Events become `std::optional<sf::Event>`; `sf::Text`, `sf::Sprite`, and `sf::Sound` have no default constructor; the `Quads` primitive is gone. The full migration notes are in "Migrating from 2D-action-game to SFML 3" in DEVELOPMENT.md.
- The audio backend is miniaudio, and `openal32.dll` is no longer shipped.
- 3.1 shapes text with HarfBuzz, which renders Chinese and Korean more reliably.
